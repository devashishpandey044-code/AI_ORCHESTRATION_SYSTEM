## What this does not prove

- The model is scripted in every eval, so these check what the code does with a model answer, not how good a real model's answers are.
- Labels and personas are written by hand, so they encode the author's own judgement.
- Thresholds (for example the 60/85/125/30 percent check-in cut-offs) are first guesses that have not been tuned on real users.
- Nothing here measures whether the advice helps a real person.
